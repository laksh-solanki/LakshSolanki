## 2. Logic Chain

1. **Router Placement Logic:**
   - From Observation 1, `/:pathMatch(.*)*` matches any URL not matched by preceding routes.
   - Therefore, the `/v/:id` route must be inserted prior to line 101.
   - Inserting `{ path: '/v/:id', name: 'PdfLanding', component: () => import('@/pages/PdfLandingPage.vue'), props: true, meta: { title: 'LakshSolanki | View PDF' } }` ensures the landing page is lazily chunked and its title automatically set to `"LakshSolanki | View PDF"`.
   - Adding `{ path: '/v', redirect: '/projects/pdf-image-studio?mode=pdf-to-qr' }` immediately after `/v/:id` handles visits where the user stripped or omitted the ID parameter, gracefully forwarding them to the PDF to QR generator.

2. **SPA Build Script Logic:**
   - From Observation 2, `create-spa-route-pages.mjs` creates entry pages for static hosting.
   - Adding `"/v"` to `spaRoutes` creates `dist/v/index.html`.
   - However, since `/v/:id` has dynamic UUID segments that cannot be enumerated at build time, hosts like GitHub Pages rely on a root `404.html` to serve the SPA.
   - Therefore, adding `await writeFile(join(distDirectory, "404.html"), indexHtml);` in `create-spa-route-pages.mjs` provides universal fallback across all static web hosts.

3. **Graceful Status Card Design Logic:**
   - From Observation 3, `NotFoundPage.vue` establishes the exact visual language for page-level errors: `#FFFFFF` card, `1px solid var(--portfolio-border-color)`, `var(--portfolio-shadow)`, `border-radius: 24px`, gradient Space Grotesk display code (`#7C0E44` to `#AA5E7A`), and pulsing radar circles.
   - From Observation 4, using `mdi-file-pdf-box` (registered in `icons.js`) ensures the radar visual renders reliably without missing-icon fallbacks.
   - For the required action buttons:
     - Primary button: `to="/projects/pdf-image-studio?mode=pdf-to-qr"` with label "Generate Your Own QR" and icon `mdi-plus`.
     - Secondary button: `to="/"` with label "Return Home" and icon `mdi-home-variant-outline`.
   - When the metadata endpoint returns 404 or 410, or when the client rejects a malformed UUID, `PdfLandingPage.vue` transitions to this status card instead of crashing or showing a blank page.

4. **Build Compatibility Logic:**
   - From Observation 5, existing Vite build and tests succeed without regression.
   - Because `PdfLandingPage.vue` is loaded via dynamic import, Vite code-splits it into its own bundle, and users encountering 404s only download the lightweight card without loading `pdfjs-dist` worker overhead.
